# AI INSTRUMENTATION ENGINE
## Intelligent Health Monitoring & Fault Diagnosis Engine

### Hackathon Pitch
The AI Instrumentation Engine bridges process automation with LLM reasoning. By combining deterministic IEC calculations with a 3-agent AI pipeline, it provides real-time field troubleshooting without hallucination.

### Quick Start
1. Clone repo
2. Create `.env` with `GROQ_API_KEY=your_key`
3. Run: `streamlit run app.py`
